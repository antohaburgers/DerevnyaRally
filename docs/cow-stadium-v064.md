# v0.64 — Ровная арена, медленные коровы и проверка турбо

- Высота всей арены и окружающего поля строго 0, нормаль [0, 1, 0]. Чаша
  полностью убрана. Деревенский фон и сцепление стадиона сохранены.
- Скорости коров, м/с: спокойно 0,8 → 0,7; настороженно 1,6 → 1,2;
  паника 3,4 → 2,5; уклонение 4,4 → 3,2. Стадо по-прежнему 30–50.
- Музыкальная подборка заранее определяется во время стартового облёта.
  Музыка включается после «ГАЗ!». Пустые MP3 отбрасываются; .MP3 поддерживается.
  Прежний пустой файл заменён владельцем настоящим arena1.mp3: 95,4 с,
  3 403 303 байта. Формат и декодирование проверены ffprobe/ffmpeg.

## Проверка двигателя

Коэффициент стока 1,00, турбо 1,30. Пик исходной кривой 209 Н·м при
3200 об/мин, турбо — 271,7 Н·м. Красная зона обоих — 6200 об/мин.
Не обнаружено подмены турбо стоком при запуске стадиона. Значение наддува
на индикаторе само по себе не добавляет ещё один множитель мощности.

Прогон исходного OffroadVehicle с настоящим RunState: одинаковые здоровые
машины HP100, шины и подвеска сток, ровный грунт стадиона, HIGH, блокировки
выключены, полный газ. Для сравнения грунт продлён, чтобы выезд на траву
не влиял на результат.

| Измерение | Сток | Турбо |
|---|---:|---:|
| Коэффициент момента | 1,00 | 1,30 |
| Скорость через 2 с | 35,11 км/ч | 40,97 км/ч |

Турбо быстрее в одинаковых условиях. Саму мощность двигателя не меняли.
При HP≤25 остаётся штатное снижение ×0,85; при отсутствии топлива отдача 0.
Автоматические тесты проверяют эти значения, сохранение преимуществ турбо,
геометрию плоской арены, предзагрузку и отбрасывание пустой музыки.
