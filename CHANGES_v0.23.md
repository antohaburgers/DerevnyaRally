# Изменения v0.23 относительно v0.22

| Файл | Изменение |
|---|---|
| controls.js | Полный lifecycle аналогового GAS, capture/release, отмена и глобальные fallback-сбросы. |
| game.js | Подменю кубка, спринты, чистый input, старт с работающим двигателем, rescue checkpoint, HUD/результаты, финишные баннеры, AI-свет и крупные ленты. |
| sprint-world.js (новый) | Конечная стандартная процедурная трасса 5/10 км, безопасные зоны старт/финиш. |
| race.js | Четыре GAME_MODE, общий прогресс кольца/спринта, интервалы checkpoints, START_LOCK, более быстрые физические AI, переключение LOW, двойной flash, сброс задержки rescue. |
| circuit-world.js | 225 м между checkpoints, поддержка конечной дороги, пространственный индекс. |
| road-world.js | Интерполированная ширина дороги и ограниченный поиск за пределами индекса. |
| race-decor.js | Крупные частые ленты вдоль дуг, двусторонние старт/финиш, более близкие зрители и группа у финиша. |
| pickups.js | Пространственный индекс бонусов для девяти AI на длинной трассе. |
| biomes.js | 51 название деревень, отдельный seeded shuffle bag без быстрых повторов. |
| run-state.js | Рекорд ENDLESS не изменяется кольцевой гонкой или спринтом. |
| index.html | Подменю КОЛЬЦО / СПРИНТ 5 КМ / СПРИНТ 10 КМ и версия 023. |
| sw.js | Новый офлайн-кеш v0.23 и sprint-world.js. |
| package.json, README.md | Версия, команды тестирования и актуальная инструкция. |
| tests/stage23.test.mjs, tests/sprint23-endurance.test.mjs (новые) | Lifecycle GAS, новые режимы, полноценные физические прогоны спринтов. |
| Остальные изменённые tests | Регрессия новых режимов, reset, интервалов и оформления; обновление cache-busting версии. |

В остальных изменённых JS-модулях обновлён только импорт `?v=022` → `?v=023`. Физическая модель Нивы, двигатель, сцепление и основная формула повреждений не переделаны. Пулы музыки и громкость сохранены; raceX используется во всех гонках.

Проверки: `npm test`, полная трёхкруговая гонка, полные спринты 5 и 10 км. Видимость лент в реальном WebGL, iOS-аудио и FPS телефона требуют живого теста — автоматические геометрические и физические проверки его не заменяют.
